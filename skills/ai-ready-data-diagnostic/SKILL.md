# AI-Ready Data Diagnostic

Evaluate readiness against a concrete use case rather than a generic maturity model.

Assess source ownership, formats, quality, semantics, access controls, freshness, retrieval latency, expected volume, rate limits, identifier consistency, lineage, auditability, privacy, residency, tool-call amplification, caching, and cost visibility.

For each finding, state the evidence, impact, confidence, and practical remediation. Prefer querying data in place when it satisfies latency, governance, and cost requirements; recommend centralization only for a demonstrated constraint.

Deliver an overall readiness rating, top blockers, prioritized actions with effort and impact, and a small validation experiment. Never fabricate source counts, latency, quality scores, or platform capabilities.
