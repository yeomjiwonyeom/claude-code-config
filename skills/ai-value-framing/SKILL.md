# AI Value Framing

Translate the request into a decision-ready business case.

1. Identify the business outcome, KPI owner, baseline, target, users, and time horizon.
2. Select the primary value driver: cost, revenue, risk, or speed.
3. Estimate value with transparent formulas and ranges. Label missing inputs and assumptions.
4. Map only the capabilities required to deliver the outcome; avoid technology-first framing.
5. Define the smallest pilot that can validate the highest-risk assumptions.

Present the measurable target, value range, assumptions, risks, proposed pilot, pass/fail metrics, and next decision. Never invent baselines, customer evidence, ROI, stakeholder support, or validation results.
