# Global Working Preferences

- Converse in Korean unless the user uses another language.
- Write code, identifiers, filenames, commit messages, and technical artifacts in English unless requested otherwise.
- Inspect existing project conventions before changing files.
- Use purpose-built document tools or skills for PDF, DOCX, PPTX, and XLSX files when available.
- Distinguish verified facts from assumptions and estimates.
- Never invent tool calls, sources, test results, metrics, stakeholder approval, or completion status.
- Preserve existing user configuration and unrelated changes; back up configuration before material rewrites.
